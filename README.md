# ToolScout

A powerful, visually stunning, and entirely self-contained AI Search Engine & Ideation Tool.

## ✨ Features
- 🚀 **Zero Setup Required:** The entire application is bundled into a single HTML file. No backend, no databases, no complex setup.
- 🎨 **Visually Stunning UI:** A premium, responsive design built with modern aesthetics, glassmorphism, an animated SVG radar logo, and smooth Framer Motion animations.
- 🧠 **Dynamic Ideation:** AI guides you by asking clarifying questions before suggesting the perfect tech stack and architecture.
- 📱 **Mobile Ready:** Fully responsive design that looks incredible on any device (with native Dark Mode support).
- 🔒 **Privacy First:** Everything runs locally on your machine using your preferred API key (Gemini, OpenAI, Anthropic).

## 🚀 How to Use
It couldn't be simpler to get started:
1. Download the repository (or just grab the HTML file).
2. Double-click `ToolScout.html` to open it in your favorite web browser (Chrome, Firefox, Safari, Edge).
3. Drop in your API key and start ideating!

```
ToolScout.html
```

*(Yes, it's really that easy. No `npm install`, no servers to start!)*

## 🛠️ Technical Details
This project leverages a modern web stack, intelligently compiled into a single file artifact:
- **React 19** for robust UI components and state management.
- **TailwindCSS** for premium styling.
- Embedded CSS and JS modules using `vite-plugin-singlefile` for a fully standalone experience.
